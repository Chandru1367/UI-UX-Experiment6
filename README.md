# UI-UX-Experiment6

## Aim

To understand and apply the UX design process by conducting solution ideation, creating user stories, developing user scenarios, designing user flow diagrams, and organizing information architecture for a Hospital Appointment Booking App.

## Algorithm
1. Identify a common UX problem.
2. Analyze user needs and pain points.
3. Conduct an ideation exercise (Crazy 8s/Brainwriting).
4. Generate multiple low-fidelity design ideas.
5. Create user personas.
6. Write user stories based on user goals.
7. Select a user story and create a narrative scenario.
8. Design a task flow diagram showing user interactions.
9. Perform information architecture activities such as card sorting.
10. Create a site map showing categorized content structure.
11. Evaluate the proposed solution and document findings.

## Solution Ideation
### UX Problem

Many patients face difficulties in booking doctor appointments due to complicated forms, unclear schedules, and lack of appointment reminders.

### Crazy 8s Ideation Exercise
1.	One-tap appointment booking
2.	Voice-based booking system
3.	AI chatbot for doctor suggestions
4.	Calendar-based slot selection
5.	Emergency priority booking
6.	QR-code hospital check-in
7.	Automated appointment reminders
8.	Video consultation booking

## Creating User Stories
### Persona 1: Ravi
1. Age: 30
2. Occupation: Software Engineer
3. Goal: Book appointments quickly
### Persona 2: Lakshmi
1. Age: 65
2. Occupation: Retired Teacher
3. Goal: Easily navigate the app and receive reminders
### User Stories
1. As a working professional, I want to book appointments online, so that I can save time.
2. As a senior citizen, I want voice assistance, so that I can use the app without difficulty.
3. As a patient, I want to view doctor availability, so that I can choose a convenient appointment slot.
4. As a patient, I want appointment reminders, so that I do not miss my consultation.
5. As a patient, I want to reschedule appointments, so that I can manage changes in my schedule.
6. As a patient, I want to view doctor profiles and ratings, so that I can choose the best doctor.
## Creating Scenario
### Selected User Story

As a working professional, I want to book appointments online, so that I can save time.

### Narrative Scenario

Ravi is a 30-year-old software engineer working from home. During his lunch break, he experiences severe headaches and decides to consult a neurologist.

He opens the hospital appointment app on his smartphone. Ravi feels concerned about his health but wants a quick and hassle-free booking process.

He searches for a neurologist, views available doctors, selects a preferred doctor, and chooses an evening appointment slot. The booking is completed within two minutes.

Ravi receives a confirmation message and appointment reminder notification, making him feel relieved and confident.

## Result

The UX design process for a Hospital Appointment Booking App was successfully completed. Multiple solution ideas were generated through ideation techniques, user stories and scenarios were created based on personas, a user flow diagram was developed to represent task navigation, and information architecture was organized using card sorting and a site map. The proposed design improves usability, accessibility, and overall user experience for patients booking hospital appointments.
